# チュートリアル

- 種別: 機能設計書
- 対象 UC: UC-011(遊び方を知る)

## 何を作るか

初めて訪れたプレイヤー、または新規登録直後のプレイヤーに操作方法・対戦ルールを提示する。サーバー側の状態は持たず、フロントエンドのlocalStorageのみで既読管理する軽量な機能。

## 入出力と振る舞い

| 操作 | 画面に起きること |
|---|---|
| トップで「遊び方を見る」を選ぶ、または未読の新規登録直後 | チュートリアル画面表示。**表示された時点で既読フラグをlocalStorageに保存する**(以後は強制再表示しない) |
| 内容を確認し「対戦を始める」 | 登録プロフィールまたは有効なゲストセッションと今回入力した名前があればチケット取得後マッチメイキング画面(UC-004)へ遷移。それ以外はHomeのゲスト入力・セッション発行(UC-003)を経由する |
| 読まずに離脱(UC-011代替フローA) | 特別な処理なし。既読フラグは表示時点で既に保存済みのため、次回以降は強制再表示しない |

UI_SKETCH.html「Tutorial」画面に対応。

## API

該当なし(サーバー側の状態を持たない)。

## 実装の配置

| 処理 | 層 | 実装先ファイル |
| --- | --- | --- |
| チュートリアル画面本体 | front | `src/front/pages/Tutorial.tsx` |
| 既読フラグの読み書き(localStorage、キー`vstetris.tutorialSeen`) | front | `src/front/lib/tutorialSeen.ts` |

## エッジケースの決定

- **空・最小データ**: 該当なし
- **上限・境界値**: 該当なし
- **エラー時に見えるもの**: localStorageが利用できない環境(プライベートブラウジング等)では、既読フラグが保存されず毎回表示されうる。致命的ではないため許容する
- **並行操作・二重実行**: 該当なし
- **再表示時の整合**: 既読フラグはブラウザ・端末ごとにローカル保存されるため、別端末でログインした場合は再度表示されうる。仕様として許容する(UC-011 BR-001は「同一環境での次回以降」を意図したもの)

## テスト方針

- 単体: `tutorialSeen`の読み書き(localStorage未対応環境でのフォールバック含む)
- 結合: 未セッション時のゲスト導線、既読で登録完了した場合に強制再表示しないこと
- E2E(golden path): 新規登録直後にチュートリアルが自動表示され、「対戦を始める」でマッチメイキングへ遷移することをPlaywrightで確認(account.mdのE2Eシナリオの一部として実施してもよい)
