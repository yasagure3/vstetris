# ユーザーストーリー

対戦テトリス(webapp, Cloudflare Workers上で稼働)のユーザーストーリー。

## ユーザータイプ

| タイプ | 説明 |
|--------|------|
| 登録プレイヤー | アカウントを作成し、継続的に対戦・戦績を積み上げるユーザー |
| ゲストプレイヤー | 登録せずニックネームだけで一時的に対戦するユーザー |
| 観戦者 | 自分ではプレイせず、進行中の対戦を見るユーザー(登録有無を問わない) |
| 運営者/管理者 | 不正対策・通報対応・サービス運用を行うユーザー |

## エピック一覧

1. アカウント・認証
2. マッチメイキング・ルーム
3. 対戦プレイ(コアゲームプレイ)
4. リアルタイム対戦同期
5. 観戦
6. 対戦結果・履歴
7. 運営・管理
8. オンボーディング

## ストーリー一覧

### Must（必須）

#### US-001: アカウント登録・ログインができる
- **As a** 登録プレイヤー
- **I want to** アカウントを登録し、ログインする
- **So that** 継続して対戦成績を貯められる

**受け入れ基準**:
- [ ] Given 未登録の状態で When 登録情報を入力して送信する Then アカウントが作成されログイン状態になる
- [ ] Given 登録済みの状態で When 認証情報を入力してログインする Then セッションが開始され対戦画面に進める
- [ ] Given 既に使われているアカウント識別子で登録しようとした場合 When 送信する Then エラーが表示され登録されない

**エピック**: アカウント・認証

---

#### US-002: 登録せずゲストとして対戦できる
- **As a** ゲストプレイヤー
- **I want to** ニックネームだけを入力してすぐ対戦を始める
- **So that** お試しで気軽に遊べる

**受け入れ基準**:
- [ ] Given トップページを開いた状態で When ニックネームを入力し「ゲストで遊ぶ」を選ぶ Then 登録なしでマッチメイキングに進める
- [ ] Given ゲストプレイヤーである場合 When 対戦を終える Then 戦績はアカウントに紐付かず保存されないことが明示される

**エピック**: アカウント・認証

---

#### US-003: ランダムな相手とオンラインマッチングできる
- **As a** プレイヤー(登録・ゲスト共通)
- **I want to** ランダムな相手と自動的にマッチングする
- **So that** 対戦相手を探す手間がない

**受け入れ基準**:
- [ ] Given マッチメイキング待機中の他プレイヤーがいる場合 When 「対戦相手を探す」を選ぶ Then 数秒〜数十秒以内にマッチが成立し対戦画面に遷移する
- [ ] Given 待機中に相手が見つからない場合 When 一定時間経過する Then 待機継続かキャンセルかを選べる

**エピック**: マッチメイキング・ルーム

---

#### US-004: ルームIDで指定した相手と対戦できる
- **As a** プレイヤー
- **I want to** ルームを作成し、IDやURLを相手に共有して対戦する
- **So that** 友人など特定の相手と直接対戦できる

**受け入れ基準**:
- [ ] Given ルームを作成した場合 When 発行されたルームIDを相手に共有する Then 相手がそのIDで入室でき対戦を開始できる
- [ ] Given ルームに1人しか入室していない場合 When もう一方が入室するまで Then 対戦は開始されず待機状態になる
- [ ] Given ルームに既に2人(対戦者)が入室している場合 When 3人目以降が同じルームIDで入室を試みる Then 入室が拒否され満室である旨が表示される

**エピック**: マッチメイキング・ルーム

---

#### US-005: テトリミノを操作して通常のテトリスとして遊べる
- **As a** プレイヤー
- **I want to** テトリミノの移動・回転・ハードドロップ・ホールドを操作する
- **So that** 通常のテトリスとして遊べる

**受け入れ基準**:
- [ ] Given 対戦が開始された状態で When 左右移動・回転・ソフト/ハードドロップのキー操作を行う Then 盤面上のミノが対応して動く
- [ ] Given ホールド操作を行った場合 When 次のミノが出現する Then ホールドしたミノと入れ替わる(1手番に1回まで)
- [ ] Given ラインが揃った場合 When ミノが着地する Then 揃った行が消え、上のブロックが詰められる

**エピック**: 対戦プレイ(コアゲームプレイ)

---

#### US-006: ラインを消すと相手に「おじゃまライン」を送れる
- **As a** プレイヤー
- **I want to** 複数ライン消去やコンボで相手の盤面に攻撃(おじゃまライン)を送る
- **So that** 対戦としての攻防が成立する

**受け入れ基準**:
- [ ] Given 2ライン以上同時に消した場合 When 消去が確定する Then 消去数に応じたおじゃまラインが相手に送られる
- [ ] Given 相手からの攻撃を受けている状態で自分もラインを消した場合 When 消去が確定する Then 攻撃同士が相殺される(相殺ルールが適用される)

**エピック**: 対戦プレイ(コアゲームプレイ)

---

#### US-007: 相手からのおじゃまラインを受け取る
- **As a** プレイヤー
- **I want to** 相手の攻撃で自分の盤面下部に「おじゃまライン」が追加される
- **So that** 対戦の緊張感と戦略性が生まれる

**受け入れ基準**:
- [ ] Given 相手が攻撃を確定させた場合 When 一定のタイミングで Then 自分の盤面下部に穴あきのおじゃまラインが積み上がる
- [ ] Given おじゃまラインの積み上げにより盤面上部までブロックが達した場合 When 新しいミノが出現できない Then 自分のゲームオーバーとなる

**エピック**: 対戦プレイ(コアゲームプレイ)

---

#### US-008: 自分と相手の盤面をリアルタイムに見られる
- **As a** プレイヤー
- **I want to** 対戦画面で自分の盤面と相手の盤面を同時に見る
- **So that** 相手の状況を把握して戦略を立てられる

**受け入れ基準**:
- [ ] Given 対戦中の状態で When 相手が操作を行う Then 遅延の少ない範囲(体感で気にならない程度)で相手の盤面表示に反映される
- [ ] Given 通信が瞬間的に遅延した場合 When 遅延が解消する Then 盤面が正しい状態に復帰する(操作不能なズレが残らない)

**エピック**: リアルタイム対戦同期

---

#### US-009: 対戦が終了すると勝敗が表示される
- **As a** プレイヤー
- **I want to** どちらかがゲームオーバーになったら対戦が終了し結果を見る
- **So that** 対戦の決着がわかる

**受け入れ基準**:
- [ ] Given 自分または相手がゲームオーバー条件を満たした場合 When 対戦が終了する Then 勝者・敗者が両者の画面に表示される
- [ ] Given 対戦が終了した場合 When 結果画面が表示される Then 「もう一度対戦」または「終了する」を選べる

**エピック**: 対戦プレイ(コアゲームプレイ)

---

#### US-010: 通信切断時の扱いが明確になっている
- **As a** プレイヤー
- **I want to** 対戦中に自分や相手の通信が切れた場合の扱いを知る
- **So that** 対戦が不当な形で終わらない、または長時間ブロックされない

**受け入れ基準**:
- [ ] Given 自分の通信が瞬断した場合 When 一定時間内に再接続する Then 対戦状態を保持したまま復帰できる
- [ ] Given 相手が一定時間再接続しない場合 When タイムアウトする Then 自分の不戦勝として対戦が終了し、次の行動(再戦・終了など)に進める
- [ ] Given 自分と相手が同時にタイムアウトした場合 When どちらも一定時間内に再接続しない Then 両者敗北(引き分け)として対戦が終了する

**エピック**: リアルタイム対戦同期

---

#### US-021: アカウント情報を管理できる(パスワード再設定・退会)
- **As a** 登録プレイヤー
- **I want to** パスワードを再設定する、またはアカウントを削除(退会)する
- **So that** ログインできなくなった場合に復旧でき、利用をやめたい場合はデータを整理できる

**受け入れ基準**:
- [ ] Given ログイン情報を忘れた状態で When パスワード再設定を申請する Then 本人確認の上で新しいパスワードを設定できる
- [ ] Given ログイン済みの状態で When アカウント削除を申請し確認する Then アカウントと紐づく個人情報が削除され、以後そのアカウントでログインできなくなる

**エピック**: アカウント・認証

---

#### US-024: 登録時に利用規約・プライバシーポリシーに同意する
- **As a** 登録プレイヤー
- **I want to** 登録時に利用規約とプライバシーポリシーの内容を確認し同意する
- **So that** 個人情報の取り扱いに納得した上でサービスを利用できる

**受け入れ基準**:
- [ ] Given アカウント登録フォームを開いた状態で When 利用規約・プライバシーポリシーに同意せずに送信しようとする Then 登録できず同意が必須である旨が表示される
- [ ] Given 同意チェックを行った場合 When 登録を送信する Then 同意した日時が記録された上でアカウントが作成される

**エピック**: アカウント・認証

---

### Should（重要）

#### US-011: 進行中の対戦をリアルタイムに観戦できる
- **As a** 観戦者
- **I want to** 進行中の対戦の一覧から1つ選んで観戦する
- **So that** プレイせずに対戦を楽しめる

**受け入れ基準**:
- [ ] Given 進行中の対戦が存在する場合 When 観戦一覧から1つ選ぶ Then 両者の盤面がリアルタイムに(観戦者視点で)表示される
- [ ] Given 観戦中に対戦が終了した場合 When 終了する Then 結果が表示され観戦一覧に戻れる
- [ ] Given 進行中の対戦が1件も存在しない場合 When 観戦一覧を開く Then 観戦可能な対戦がない旨が表示される

**エピック**: 観戦

---

#### US-012: 対戦後に結果の詳細を確認できる
- **As a** プレイヤー
- **I want to** 対戦終了後に勝敗・消したライン数・送った攻撃量などの詳細を見る
- **So that** 自分の実力や課題を把握できる

**受け入れ基準**:
- [ ] Given 対戦が終了した場合 When 結果画面を見る Then 勝敗・スコア・消去ライン数・攻撃量などのサマリーが表示される

**エピック**: 対戦結果・履歴

---

#### US-013: 過去の対戦履歴・戦績を確認できる
- **As a** 登録プレイヤー
- **I want to** 自分の過去の対戦履歴と通算勝敗を見る
- **So that** 自分の成長を実感できる

**受け入れ基準**:
- [ ] Given ログイン済みの登録プレイヤーの場合 When 履歴ページを開く Then 過去の対戦が新しい順に一覧表示される
- [ ] Given ゲストプレイヤーの場合 When 履歴ページを開こうとする Then 履歴が保存されていない旨が案内される

**エピック**: 対戦結果・履歴

---

#### US-015: 不適切な行為を通報できる
- **As a** プレイヤー
- **I want to** 不適切なニックネームや行為を運営に通報する
- **So that** 健全な対戦環境が保たれる

**受け入れ基準**:
- [ ] Given 対戦中または対戦後の画面で When 「通報する」を選び理由を送信する Then 運営側に通報内容が記録される

**エピック**: 運営・管理

---

#### US-022: 記録された通報の一覧を確認できる
- **As a** 運営者/管理者
- **I want to** プレイヤー・観戦者から送られた通報の一覧を確認する
- **So that** 対応要否を判断できる

**受け入れ基準**:
- [ ] Given 通報が1件以上記録されている場合 When 通報一覧画面を開く Then 通報日時・通報者・対象・理由が一覧表示される
- [ ] Given 通報が1件も記録されていない場合 When 通報一覧画面を開く Then 通報がない旨が表示される

**エピック**: 運営・管理

---

#### US-023: 初めて訪れたプレイヤーが操作方法とルールを確認できる
- **As a** 初めて訪れたプレイヤー
- **I want to** 操作方法(移動・回転・ハードドロップ・ホールド)と対戦ルール(おじゃまライン等)の説明を見る
- **So that** 対戦にスムーズに入れる

**受け入れ基準**:
- [ ] Given 初回訪問(またはチュートリアル未読了)の状態で When トップページを開く Then 操作方法とルールの説明を見る導線が提示される
- [ ] Given チュートリアルを最後まで見た、またはスキップした場合 When 次回以降アクセスする Then 強制的には再表示されない

**エピック**: オンボーディング

---

### Could（あると嬉しい）

#### US-016: 観戦中にリアクションできる
- **As a** 観戦者
- **I want to** 観戦中の対戦に対して簡易リアクション(スタンプ等)を送る
- **So that** 対戦をより楽しめる

**受け入れ基準**:
- [ ] Given 対戦を観戦している状態で When 用意されたリアクション(スタンプ等)を選択する Then 選択したリアクションが観戦中の画面に表示される
- [ ] Given 短時間に連続してリアクションを送ろうとした場合 When 送信回数が一定の上限を超える Then 送信が制限される(スパム防止)

**エピック**: 観戦

---

#### US-017: 対戦のリプレイを見返せる
- **As a** 登録プレイヤー
- **I want to** 過去の対戦の操作ログを再生して見返す
- **So that** 反省・上達に役立てられる

**受け入れ基準**:
- [ ] Given 登録プレイヤーが過去に対戦したログが保存されている場合 When リプレイを選択して再生する Then 対戦開始から終了までの操作が時系列で再現される
- [ ] Given リプレイ再生中の場合 When 一時停止・再開・シークを行う Then 再生位置が操作に応じて変わる

**エピック**: 対戦結果・履歴

---

#### US-025: 自分の見え方・環境に合わせて対戦できる(アクセシビリティ)
- **As a** プレイヤー
- **I want to** ミノを色だけでなく模様や記号でも区別でき、キー割当を変更できる
- **So that** 自分の見え方や環境に合わせて対戦できる

**受け入れ基準**:
- [ ] Given 色覚サポート設定を有効にした場合 When 対戦画面を表示する Then ミノが色に加えて模様や記号でも区別できる
- [ ] Given キー割当を変更した場合 When 対戦中に操作する Then 変更後のキーで意図した操作が行われる

**エピック**: 対戦プレイ(コアゲームプレイ)

### Won't（今回はやらない）

#### US-018: フレンド機能・ランキング/レーティング表示
今回のスコープでは対戦(1vs1)と観戦のコアのみに絞り、フレンド管理やランキング表示などのSNS的機能は対象外とする。

#### US-019: 3人以上のマルチプレイ(バトルロイヤル形式)
今回は1vs1対戦を軸とする。3人以上が同時に対戦するモードは対象外とする。

#### US-020: 運営者向けの不正対策自動検知・BAN機能の高度化
通報の受付・記録(US-015)までを対象とし、自動検知やBAN処理フローの詳細設計は対象外とする。

#### US-026: 不正操作・チート対策(サーバー権威検証等)
クライアントの操作を検証してチート行為を検出する仕組み(異常な操作速度の検知、サーバー権威によるロジック検証など)は今回のスコープでは対象外とする。将来的な拡張候補として記録しておく。

## 運営者/管理者ストーリー(補足)

運営者/管理者は主にプレイヤー/観戦者からの通報(US-015)を受け取る受け手として登場する。今回のスコープでは管理画面の詳細設計(US-020参照)までは行わず、「通報が記録される」ところまでを対象とする。
